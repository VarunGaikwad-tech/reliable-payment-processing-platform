# Frontend

React + Vite frontend for the Reliable Distributed Payment Processing Platform.

## Stack

- React
- TypeScript
- Vite
- React Router
- TanStack Query
- Nginx

## Responsibilities

The frontend provides:

- Authentication
- Dashboard
- Account management
- Fund transfers
- Transaction history
- Notifications

The frontend communicates with the Node.js backend API.

## Development

```bash
npm install
npm run dev
